# Changelog

## [0.1.0] — 2026-11-11 (Early Access)

First GitHub source/wheel release of Pausio Studio: local-first video ingest, editable silence-cut proposals, waveform timeline, preview and MP4 export, standalone MLX Whisper transcription on Apple Silicon, reviewable burned-in social subtitles and portable deterministic editing instructions. Includes private session/autosave recovery, configurable subtitle styling and font families, and UI/CI regression tests.

Known limitations: no standalone signed macOS installer, no semantic editing, and no completed real-footage Mac/Samsung A56 quality acceptance tests. See the [release notes](.github/release/v0.1.0.md).
